安装
```shell
sudo apt-get update && sudo apt-get install -y acpi
```

用法
```shell
# 显示电池与温度信息
acpi
# 仅显示电池状态
acpi -b
# 显示温度信息
acpi -t
# 显示散热设备信息
acpi -c
# 温度以华氏度显示
acpi -tf
# 显示所有信息（电池、温度、风扇等）
acpi -V
# 从 /proc 而非 /sys 获取信息
acpi -p
```

查看
```shell
acpi -i
# 输出示例：
# Battery 0
# design capacity: 5900 mAh
# last full capacity: 5700 mAh
# battery technology: Li-ion
# design voltage: 11.1 V
# cycle count: 123
# condition: Good, 96.61% of design capacity

acpi -s
# 输出：battery 0 Discharging 93% 02:41:13
```
